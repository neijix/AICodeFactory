AICodeFactory settings

Where AICodeFactory works

Each folder here is its own environment: a folder that holds your projects, with its own label, skills and step agents in its .ai-root/environment.json. The label work makes it a work environment (work skills on, personal skills and MLX off). Every git project directly inside it gets the AI files at session start. Each environment has its own skills folders, and the page checks that each of its projects is set up for AICodeFactory (aicf doctor, check-only).

Your personal skills

Your personal overlay: a folder (often a private repo) whose skills/ sub-folder holds your own skills. They are on in personal roots, off at work unless an environment turns them on.
