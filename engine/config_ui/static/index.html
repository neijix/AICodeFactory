AICodeFactory settings

Where AICodeFactory works

A code root is a folder that holds your projects. Every git project directly inside one gets the AI files at session start. Adding a folder writes its .ai-root/environment.json.

Your personal skills

Your personal overlay: a folder (often a private repo) whose skills/ sub-folder holds your own skills. They are on in personal roots, off at work unless a root turns them on.
